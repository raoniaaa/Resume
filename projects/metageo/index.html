01 / SELECTED CASEMULTI-TENANT GEO PLATFORM

metaGEO多租户 GEO 智能监测平台

为品牌 GEO 运营与 Agency 白标交付构建的全流程平台，将舆情采集、内容清洗、查询生成、多模型监控、分析与报告串成可恢复、可计量的 Agent 工作流。

项目概览个人职责系统架构核心模块技术取舍项目结果

01 / OVERVIEW

把分散的 GEO 操作，组织成一条可运行的生产链路。

平台服务于品牌 GEO 运营和 Agency 白标交付。核心问题不是单次调用模型，而是如何把采集、清洗、分析、QRW、探针、多模型监控与报告生成组织为有状态的长任务，同时在多个租户之间保证数据、配额、密钥和会话隔离。

CONTEXT

业务链路长、参与角色多

平台运营方负责租户、定价和 Key；Agency 管理员负责员工与用量；员工负责品牌监控和报告。三类入口需要独立会话，同时共享同一套平台能力。

PROBLEM

Agent 长任务容易失控

采集和模型调用存在失败、限流与耗时波动。刷新页面、局部失败或重复执行都可能造成计算浪费，需要明确阶段、状态、进度、恢复点和重试边界。

GOAL

端到端可观测

从搜索任务到最终报告，每一步都能查询 stage、status 与 progress；问题、回复、引用、调用方式和耗时均被持久化，便于复盘和聚合。

BOUNDARY

平台与 Agent 解耦

BFF、租户鉴权、钱包计量与业务工作流保持清晰边界，使前端白标交付、平台运营和 Agent 服务可以独立演进。

02 / RESPONSIBILITY

我的工作覆盖工作流、平台能力和稳定性链路。

01

GEO Agent 工作流编排

以 Go/Gin 串联 MCP 搜索、详情与评论抓取、清洗、分析、QRW、探针、多模型监控和 HTML 报告，建立统一阶段状态与前置条件校验。

02

采集与清洗任务化

将小红书链路拆分为关键词搜索和 Feed 详情/评论抓取两阶段任务，使用 goroutine 并发拉取，逐条记录成功、失败与评论数量。

03

多租户与计量能力

围绕 Tenant 上下文隔离品牌、报告、用量、钱包和 API Key，并补充限流、IP 白名单、Webhook 与用量计费。

04

恢复、缓存与 BFF

为长任务加入 Checkpoint、状态恢复和热点步骤缓存；通过 BFF 隐藏平台密钥、代理业务 API 并承接浏览器会话。

03 / ARCHITECTURE

平台层负责边界，工作流层负责执行。

请求从三类用户入口进入 BFF 与业务 API，经 Tenant 上下文确定隔离范围，再进入 Agent 工作流。每个阶段将状态、结果和用量写入持久层，缓存只用于减少可重复计算，不替代真实业务状态。

04 / CORE MODULES

六个模块构成完整 GEO 交付闭环。

01

采集管线

关键词搜索先生成 Feed 集合，再并发拉取详情和评论。结果保留逐项状态，避免单个来源失败拖垮整批任务。

02

内容清洗

清洗结果按品牌与 Feed 建立 24 小时缓存，在保证业务时效性的同时减少重复抓取和 LLM 清洗开销。

03

QRW 与探针

基于品牌、受众和内容分析生成问题重写与监控探针，并通过前置状态约束确保使用的是完整上游数据。

04

多模型监控

并发调用豆包、DeepSeek、通义千问和 Kimi，记录回复、引用来源、调用模式与耗时，聚合可见度、提及率、情感和竞品信息。

05

Prompt 工程化

将清洗、QRW、探针、监控分析和报告 Prompt 版本化存入 MySQL，以 Go text/template 注入变量，并用 JSON Schema 约束输出与失败重试。

06

白标 SaaS

支持平台运营、Agency 管理员和员工三层入口；API Key scope、IP 白名单、限流、钱包、用量事件和 Webhook 组成交付边界。

05 / ENGINEERING DECISIONS

关键取舍围绕隔离、恢复与成本展开。

工作流状态入库

仅依赖前端步骤状态更简单。

选择服务端 stage/status/progress 与前置校验，换取刷新恢复、失败重试和跨端一致性。

缓存清洗结果

每次重新清洗最直接，但重复消耗采集和模型资源。

以品牌和 Feed 作为缓存维度，并设置 24 小时有效期，在时效和成本之间取平衡。

BFF 隐藏密钥

浏览器直连平台 API 开发量更小。

由 BFF 注入官方 Key 并代理业务接口，避免密钥暴露，同时承接白标前端和浏览器会话。

租户公平限流

全局并发池可能被单个大租户占满。

按租户策略分配官方 API 与 MCP 请求，让共享资源在多个租户间保持可预测。

06 / OUTCOME

从一次性脚本，升级为可运营的平台能力。

全流程

采集、清洗、分析、监控和报告处于同一工作流语义中。

可恢复

Checkpoint、阶段状态、进度轮询和缓存降低长任务失败成本。

多租户

角色、会话、数据、Key、钱包和用量形成完整 SaaS 边界。
